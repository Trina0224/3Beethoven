# Semantic curriculum comparison

Authorized continuation after V56 and the offline teacher correction pass. Trigger: both V56 students failed all six old verbal affine second-moment questions and all four neither-switch questions, yet every compared model got all 24 explicitly symbolic moment diagnostics right. Prior expansion did not adequately cross wording, context and probability representation. The prior 720-label numerical audit found no disagreement; 12 unsupported teacher mean fields were removed, 15 formatting-rejected targets recovered, and 24 legacy prompts clarified, yielding 750 corrected rows.

Hypothesis: explicit event-state and average-of-squares wording contrasts will improve transfer more than repeated practice with existing weak-family questions. Evidence against: no gain over a matched-row repeat control, or historical skill regression. This is a prospective experiment after observing the above failures, not a claim of an already demonstrated cause.

Data: keep the corrected 750 rows in both arms. Add 256 examples per arm. Semantic-course arm: 16 new independent-event stories x 5 targets x 2 wordings =160; 16 new affine-moment stories x 3 targets x 2 wordings =96. Vary success/failure descriptions, fractions (including denominators other than 100), percentages, contexts, and verbal operation scope. Answers are explicitly assistant-authored/corrected numerical supervision, independently checked by event enumeration and expanded moment identities; no new cloud teacher calls. Repeat-control arm: 256 deterministically sampled existing event/moment rows matched to supplement target counts, no novel mathematical cases. Both total 1006 rows. This compares complete content packages at matched example/update counts; prompt lengths and supervised token counts may differ, so it does not isolate one wording component.

Holdout: freeze 8 new event stories x5 targets x2 paired wordings plus8 new moment stories x3 targets x2 paired wordings =128, with mathematical identities disjoint from all available historical training/evaluation questions and the new train split. One familiar formulation and one reserved verbal formulation share each holdout's parameters. Hold out new event contexts as well. These are researcher-designed diagnostics, not an external benchmark. Existing 112 old/chain/event validation questions are development checks after their failures guided this change, not an untouched test.

Training: exactly two new students, repeat_control and semantic_course, both start the original v15 adapter, seed2027, same NF4/FP16 numerical preparation as V56, LR5e-6, batch1 accumulation8, one epoch, constant schedule, 126 updates each. Save a final adapter per arm. Final checkpoint is fixed before seeing outputs; no best-checkpoint search or additional seed runs. Evaluate original v15, prior V55 seed2027 step65, and both fixed new students on the same 112 historical checks and 128 fresh questions. Preserve unchanged raw generations; existing grader and retention gates stay unchanged. Resolve pending equivalences by explicit structural/domain proof, never numerical agreement alone. Report paired familiar/verbal and family scores.

Stop: maximum252 optimizer updates, 960 evaluation generations, zero teacher calls, and 165 GPU minutes. If service failure interrupts, inspect the error and resume only from a verified existing checkpoint without silently restarting or adding epochs. No promotion unless the original historical per-family gates pass and the new student improves on both original v15 and the repeat control on the fresh verbal half. No automatic deployment. Save only necessary adapters, curriculum/source and compact result evidence once at completion. Stop the GPU afterward. If curriculum still fails, report the failure without another unplanned round.
