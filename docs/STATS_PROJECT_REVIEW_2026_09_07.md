## 我需要修正的方向判斷

1. **目標已經漂移。**原問題是「教師能否把解題能力教給較小學生」。後來逐漸要求同一學生反覆補新概念、保留全部舊能力、跨措辭泛化，變成持續學習問題。v18–v20 的新教材主要是程序生成，搭配歷史教師 replay；不能把全部新增收益都稱為新教師蒸餾的效果。回應蒸餾本來就可以透過教師答案做 SFT，但必須保留教材來源的區別。
2. **我先前太快把深度排序當成優先解法。**概念關係值得保留在教材中；v18 卻沒有支持排序優勢。新教材可以同故事比較不同所求量，並持續混合不同深度；暫不再增加一次排序對照。這不是證明課程學習無效，而是本案尚無理由優先押注它。
3. **「沒覆蓋」不能直接當成退化原因。**v20 replay 已有 `63*(383/60)` 的秒／分鐘例題，也有 `6**2*147+(6*20+10)**2` 的二階動差例題。兩個 seed 仍共同失去 7 題 `/60` 與 5 題變異數項。這支持可重現的干擾方向；情境覆蓋、表示方式與訓練更新各有可能，尚未完成因果區分。Adding 句式缺口是 v19 的具體線索，不能拿它解釋所有後續錯誤。
4. **資料筆數高估了內容的廣度。**v20 的 192 筆新教材來自 24 組參數故事×4 種事件×2 種句式；那一組事件測試的機率分母固定為 101。它有對照教學價值，但不是 192 個獨立情境，也不是廣泛自然語言泛化測試。96/96 是要求更強測試的理由，本身既不證明記憶，也不證明理解；不存在「真的理解應該只能考八十幾分」的固定準則。
5. **保留驗證有實際缺口。**v20 基準 interval 等價式複核後，31415 第 24 步的 4/6 低於正確門檻 5/6；自動選點曾誤放行。舊驗證 moment 原本 0 分，也保護不了另一組已有 10/24 的二階動差能力。選點前就必須解決判分與覆蓋問題，不能等結果出來再補。

檢查的程式路徑有 user prompt 遮罩、回答 token 訓練、長度溢出檢查、原 v15 parent 雜湊及有限數值權重檢查；未看到足以把本次現象解釋為「根本沒訓練」的明顯錯誤。這不是完整系統無誤保證。現有證據也不足以歸因 3B 容量上限、QLoRA rank 或量化；尚無固定教材下的相應控制實驗。

統計領域仍合理：能用獨立計算器核對答案，還能具體定位漏單位、漏事件與漏動差項。問題在於把成功目標擴張得太快，以及評估和教材未同步跟上；不必因此否定領域選擇。持續學習文獻將 replay、更新約束與情境分離視為不同方法，沒有一條保證以固定 replay 比例解決所有失效的規則。[文獻：Continual Learning and Catastrophic Forgetting](https://arxiv.org/html/2403.05175v1)

## 三條路線的取捨

| 路線 | 具體做法 | 能回答什麼 | 成本與限制 | 判斷 |
|---|---|---|---|---|
| **A．完整教材，對照兩個起點** | 同一份全部任務教材；原始 Llama-3.2-3B-Instruct 加全新 LoRA，對照原 v15 接續微調；相同兩個 seed，共四次訓練。 | 目前表現是否受這條訓練歷史限制；同一 3B 能否在這份教材及預算下兼顧各項能力。 | 教材稽核與測試是主要成本；可能四次都未達標。 | **優先。**最貼近原本的蒸餾目標，也較能改變下一步決策。 |
| **B．固定短步驟，再輸出算式** | 如「單位換算→參數→所求量→算式」，教師提供精簡且可核對的步驟；工具只負責執行。 | 顯式中間步驟能否讓組合更穩定、錯誤更容易定位。 | v13／v15／v16 已有相關嘗試，需明確說清新差異；會改變輸出契約，不能直接套舊分數比較。 | A 未達標且仍想提升單一模型時，再選擇；不與 A 同時改。 |
| **C．固定專家並路由** | 保留 v15 與事件專家，依真正輸入選用適合的 adapter；不做權重直接混合。 | 能否先做出可用的 demo。 | 路由也會錯；混合概念問題未必有單一專家能解；不能偷用測試 family 標籤當路由答案。 | 使用體驗優先時可選；不等於單一學生完成能力整合。 |

B 有外部研究依據，但不是本案成功保證：教師推理作輔助監督可改善部分小模型任務；程式中間表示加執行器也有先例。它們支持「值得設計對照」，不支持「加長解說一定有效」。[Distilling Step-by-Step!](https://aclanthology.org/2023.findings-acl.507/)、[PAL](https://proceedings.mlr.press/v202/gao23f.html)

## A 如何做到一次就能作決定

**先釐清對照。**「原始 3B 重新微調」是使用既有預訓練／指令模型，加新的 LoRA；不是從隨機權重預訓練。v9 曾從原生模型訓練，v19／v20 也已混合新舊資料；新問題是「目前完整任務集、同一份教材下，原生起點與原 v15 起點的比較」，不是第一次聯合訓練。

1. **老師 quota 用來增加有意義的差異。**教材覆蓋歷史題型、四類組合能力與四事件，標記重疊概念；增加獨立故事、條件順序、單位、數字表示與容易混淆的所求量。同一情境可以對照「恰一個／兩個／都沒有／兩者相同」及「平均數／變異數／二階動差」。先用約 100–200 個獨立故事檢查教師產物品質，再依覆蓋缺口定總量；這是規模草案，不是已知最佳數量或自動擴充承諾。算式與短解說都由獨立程式／規則核對，保留原教師回答及拒收理由。
2. **資料與評分先固定。**按故事、模板及改寫血緣分割，變體不能跨訓練、驗證、新測試；教師產生訓練資料時不接觸測試。先用獨立開發例處理等價式，再鎖住判分與 prompt。新測試保留未教句式及跨單位／跨概念組合。已看過的舊測試保留為回歸基準，不再稱作未曝光測試。
3. **兩起點、相同兩個 seed。**兩路用同一份教材、相同新訓練 token／更新上限、相同 checkpoint 時點與評估規則。每一 seed 共用資料抽樣與排序規則，LoRA 初始化隨該 run 設定。原 v15 有歷史訓練成本，所以這不是全生命週期等算力比較，也不是單獨隔離「教材順序」的因果實驗。兩個 seed 提供初步複驗，不足以精確估計波動。
4. **先定何時停止，避免擴大資料卻暗中多訓很多步。**最大更新數、token 預算、逐類保留容許幅度、新能力最低目標及計算方式須寫進可執行 protocol 後才開跑，不把資料擴大後的一 epoch 等同 v20 的 48 步。第一次驗證同時達到新能力與保留要求即可停；只維持原水準、或只降低 loss 都不算成功。沒有合格 checkpoint 就標記失敗，不能用獨立測試挑點或延長到過關。
5. **每次 run 只交付同一份精簡結果。**逐類新舊分數、配對翻題與代表錯誤、訓練曝光量、權重與雜湊一併保存。以故事為單位處理相關變體；永久 MC 的 240 次回答來自 60 題×4 排列，不能當 240 個獨立觀察。只評估驗證選出的 checkpoint，必要的同時點診斷用驗證資料完成，不恢復每版一串補充測試。

原始模型與原 v15 都要在同一組新凍結測試上有基準。若要宣稱教師到學生的能力移轉，還需在預先指定的一組獨立題上報教師表現，並與獨立參考答案比較；不能只比較學生訓前訓後就宣稱完整蒸餾因果。

| 一次比較的結果 | 接下來的決定 |
|---|---|
| 原生起點兩 seed 達標，v15 路線未達標 | 採原生起點的完整教材路線；支持避開目前訓練歷史有幫助，不宣稱已找出唯一機制。 |
| v15 路線兩 seed 達標，原生路線未達標 | 保留 v15 的累積價值，採完整教材接續；結論限於本次新增訓練預算。 |
| 兩路都達標 | 依事前約定的逐類表現與成本選擇，結束補洞，不再追單題最高分。 |
| 只有單一 seed 達標，或兩路皆未達標 | 不升級，不自動加第三條調參線；決定轉短步驟介面、專家 demo，或就此收束文章。不能直接宣判 3B 容量不足。 |

**最終建議：**教學文章現在已經有足夠而且誠實的內容；無需等到所有題型全對才算完成。若還要投入，投在上面這一次有界限的比較。更多 teacher quota 能改善教材品質與廣度，但不會自動消除評估、驗證和持續修補的時間成本。

本 review 取代[流程文件第 8 節](STATS_V01_V19_RESEARCH_FLOW.md)原先 A／B／C 的優先次序；舊草案保留為當時討論紀錄。本次沒有採用新模型、生成新教材或安排訓練。
