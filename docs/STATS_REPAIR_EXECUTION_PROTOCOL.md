# 固定權重重現與修復執行協議

2026-09-07 PDT，新的 GPU 推論／更新前記錄。使用者要求依診斷實際解決並繼續，自主完成必要工作。

## 先做的控制

使用 Kaggle Version 53 的原 v15、31415 step24、step33，保留原底模 revision、NF4／FP16、單一可見 GPU 與 Transformers 5.0.0。每個權重重播既有 112 道選點題，另測固定 192 筆 replay 中 interval、poisson_time、uniform_time 三類各 24 筆。共至多 552 次回答，不呼叫教師、不改權重。按原始 SHA 驗證載入；原始回答與題目不改。新 replay 分數是教材擬合診斷，不能當泛化分數。

假設與分歧：若重載答覆與存檔有實質差異，先查載入 dtype、prepare_model_for_kbit_training 與 cache 等執行條件，禁止把不一致誤當新訓練效果。若可重現且教材原題好、不同表述題差，則支持表述依賴；若教材也退步，則優先處理更新干擾。兩種都不是能力上限證明。完全相同的答案以 raw hash 衡量，等價式另列，數學分數不替代重現率。

## 有上限的修復分支

控制確認後才定案實際修復，並在任何更新前追加具體設定與 hash。優先修已證實的執行 bug；沒有 bug 證據時，不亂改 grader。允許最多兩個 seed 的一遍修復試驗，總計最多 66 optimizer updates；來源仍為已驗證教材，不加入選點／測試題。若改資料或學習率，執行前明列單一主要變因與預期，不以追逐驗證分數反覆追加版本。GPU 本段上限 90 分鐘；教師新呼叫 0。若到上限未改善，保存失敗與可驗證的原因，不宣稱修復完成。

任何修復沿用既有 112 題的逐類保留／事件門檻，不能靠改低標準成功；已曝光選點只作選點。原 v15 永遠保留。通過選點的候選才依事先規則執行原獨立 holdout；本協議不把教材診斷當獨立測試。每個模型均保存 adapter、資料／原答／環境／來源 hash、修正前後表與可下載 ZIP。先完成可重現控制和一個有證據的修復回合，再回報；例行環境與解析問題自行處理。
