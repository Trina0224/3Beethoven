## 判分

自動主要分＝所有綁定值正確、表達式結構可確認、精確計算值正確。
結構比較允許加法／乘法交換與結合、冗餘括號，不只是原始字串完全相同。
其他等價改寫可能無法自動確認：若數值相同但結構不同，標為 review_required，
保留 raw 供後續語意審核，不立即判作數學錯誤，也不自動給分。
自動分是保守初步分數；不得未複核就宣稱學會或失敗。
Bindings 數值可用等值分數表達。只輸出最終答案不能取得自動列式分。
限制運算語法，不使用 Python eval。

另報綁定正確率、可執行率、工具計算答案正確率、需複核數與各題型結果。
工具計算分不得冒充學生心算分；解析與格式失敗須與概念錯誤區分。
本輪是探索性試驗，未設事後「達成成功」門檻；先看同题逐題差異及保留能力。
