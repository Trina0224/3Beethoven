## 兩個不同問題

- v15 訓練流程的變異：從同一個保存的 v14 checkpoint 出發，沿用凍結 v15 訓練資料、超參數與選點規則，只改訓練 seed。來源以原 `run_stats_v0_15.py`、其 SOURCE_SHA 與已保存老師回覆核對；不重新生成老師答案。
- v19 修復流程的變異：三次都從原本同一份 v15 adapter（SHA 9369d52de4a886df9da0c872cd41bd4e01af0a38bf02ad724b5951c1a6b9f5d3）出發，沿用 v19 480 筆資料、LR 2e-5、batch 8 與停止規則，只改訓練 seed。這量的是修復流程變異，不是 v15 本身訓練流程變異。

預定 seed 為 1919、2027、31415；開始前另凍結執行 manifest、套件、基底／tokenizer／adapter hashes。原有 seed 1919 run 只有在完整設定可證相同時才併入；否則同一環境重跑，歷史值另列。不得因某 seed 較好而只報它，或以測試結果調整其他 seed。

## 報告尺度

每次跑同一份永久 MC／列式錨點與固定擾動集，保存每 seed、每題原始答案、訓練步數與是否觸發保留門檻。報各 run 成績、平均、樣本標準差、範圍、各 family 的保留情況；自動與語意複核分開。跨題抽樣誤差與跨訓練 run 變異不可混用。

三次只足以看明顯不穩定，是初步估計，不是精確噪音底線。若三次差異很大，先分析造成波動的項目，再按事前追加規則決定是否需要更多 run。不能靠改 greedy inference seed 取代重新訓練。

## 本輪界線

固定權重擾動先回答現有滿分對句式與量級是否穩健，並釐清恰有一個事件的錯誤形態。這些分析完成前不追加訓練；本文件保留下一輪可以直接執行的比較方向，不將未執行的多 seed 結果寫成已知。
